Ollama Setup

Install and run Ollama so you can code with free local AI models. No account, no API key, nothing leaves your machine.

What is Ollama? A free, open-source tool that lets you download and run AI models on your own computer. Ollama is the player; the AI model is the recording. Install once, then pull whichever models you want.

Step 1: Install Ollama

  1. Go to https://ollama.com in your browser.
  2. Download Ollama for your computer (Windows, Mac, or Linux).
  3. Run the installer and follow the prompts. Accept the defaults.

Step 2: Verify the installation

Open a terminal (Command Prompt or PowerShell on Windows, Terminal on Mac or Linux) and type:

ollama --version

You should see a version number, for example:

ollama version is 0.6.x

If you see “command not found,” close and reopen your terminal and try again. On Linux, you may need to log out and back in.

Step 3: Confirm Ollama is running

ollama list

An empty list is normal — you have not downloaded any models yet. No error message means Ollama is working.

Step 4: Pull a coding model

Choose a model and download it. Recommended for beginners:

ModelSizeGood for
qwen2.5-coder:3b~2 GBLearning, fast answers, older computers
deepseek-coder:6.7b~4 GBStronger coding help
codellama:7b~4 GBAll-around coding assistant
 
ollama pull qwen2.5-coder:3b

Wait for the download to finish. You only need to do this once per model.

Step 5: Chat with your model

ollama run qwen2.5-coder:3b

Type a question and press Enter:

>>> Write a Python function that adds two numbers

Type /bye to exit, or press Ctrl+D.

Quick command reference

CommandWhat it does
ollama --versionShows the installed Ollama version
ollama listLists models on your machine
ollama pull <model>Downloads a model
ollama run <model>Starts a chat session
/byeExits a chat session
ollama stop <model>Stops a running model
ollama rm <model>Deletes a model to free disk space

Troubleshooting: slow download? Check your internet — you only need it to download the model. Model runs slowly? Try the smaller qwen2.5-coder:3b model. Connection refused? Restart your computer and run ollama list again.
