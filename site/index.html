Free AI Coding with Local Models

A beginner-friendly manual for writing code with free, local AI models. No account, no API key, nothing leaves your machine. Written in plain English, step by step, never condescending — like a friend would explain it.

Who this is for: anyone who wants to code with AI without creating accounts or sending code to cloud services. You do not need a computer science degree — if you can copy and paste, you can use this guide.

How to use this site

  1. Read index.html start to finish, or open any section page from the navigation.
  2. Install Ollama using ollama-setup.html.
  3. Try the prompts in code-prompts.html, one at a time.
  4. Keep cheat-sheet.html printed on your desk.
